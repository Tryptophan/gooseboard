# Gooseboard

Peer-to-peer infinite canvas: notes (rich text/markdown), freehand ink, files, folders and link cards, shared live between 2+ browsers over WebRTC. No accounts: your name/colour and board list live in `localStorage`, board data in IndexedDB.

- **Stack:** Vite, React 18, TypeScript, Yjs (CRDT), y-webrtc (full mesh), Tiptap, perfect-freehand, CSS Modules.
- **Boards:** `/#/board/<8-char base62 id>`. The id is the room name, so keep links private.
- **Files never go into the doc.** The owner's disk serves bytes on demand over the existing data channels (chunked, backpressure, resumable). Thumbnails (images/video frames) are generated by the owner. Disk folders are listed and thumbnailed live. Chromium persists file handles; Firefox needs a re-pick after reload, and the owner is prompted to relink when someone asks.
- **Mirroring.** Metadata syncs first; the owner then adds a content hash (SHA-256 over 4 MiB block digests). Files ≤ 2 MB replicate to every peer's IndexedDB cache in the background. Larger files are fetched on request, and once someone has one (saved file handle on Chromium, in memory for the session on Firefox) they serve it too. Disk-folder files join in once someone opens them. Peers advertise what they hold, requests go to the owner or any holder and fail over mid-transfer, and receivers verify the hash. Cards show synced / syncing / not synced / unavailable plus how many online peers have a copy. Cached copies a board no longer references are dropped the next time it loads.

## Develop
    npm install
    npm run dev          # http://localhost:5173
    npm run lint && npm run typecheck && npm run build

## Signaling (no server)
Signaling only introduces peers, and there is no server to run. y-webrtc's signaling (topic pub/sub) is carried over public **Nostr relays** (ephemeral events) and **WebTorrent trackers** (the opaque offer payload) at the same time; see `src/net/signal/` and the lists in `src/config.ts`. Topics are hashed and every handshake is encrypted with the board id (y-webrtc room password), so relays see only ciphertext and people without the link can't join. Any one relay or tracker being down is fine. There is no TURN: strict NATs may fail to connect.

## Deploy
`.github/workflows/deploy.yml` lints, typechecks and builds on every push/PR, and deploys `main` to GitHub Pages (base `/<repo>/`). Enable Pages > Source: GitHub Actions.
